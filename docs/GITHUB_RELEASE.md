`MinimalClock`

## Short description

A lightweight, configurable Rainmeter desktop clock for Windows with a matching dependency-free HTML/CSS/JavaScript implementation.

## v1.0.0 release title

`MinimalClock v1.0.0`

## Draft release notes

MinimalClock v1.0.0 is the first stable release of a lightweight, typography-first desktop clock for Windows.

### Highlights

- native Rainmeter implementation with no plugins or network calls
- 12H / 24H modes
- optional seconds with automatic layout reflow
- scale, opacity, and color-theme presets
- native settings panel with persistent configuration
- matching dependency-free HTML/CSS/JavaScript implementation
- repeatable CPU and memory benchmark tooling
- Windows CI validation through GitHub Actions
- packaged as a standard `.rmskin` installer

### Measured performance

On the development test system, MinimalClock added approximately:

- seconds hidden: +0.0057 percentage points CPU and +2.17 MB working set
- seconds shown: +0.0258 percentage points CPU and +2.35 MB working set

The measurements are specific to one machine and are included as evidence rather than universal requirements.

### Install

Download `MinimalClock_1.0.0.rmskin`, open it, and install through Rainmeter.
