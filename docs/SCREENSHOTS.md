# Release screenshots

The screenshots should show MinimalClock as a real desktop utility, not as a staged mockup.

## Main README image

Use the native Rainmeter version at 100% scale with:

- 24-hour mode
- seconds shown
- 100% opacity
- White theme
- a dark or moderately busy wallpaper with enough contrast
- no Rainmeter manager window or other setup UI visible

Crop tightly enough that the clock is readable, while leaving enough wallpaper to show that it is a desktop skin.

## Secondary images

Capture:

1. Native clock, seconds shown
2. Native clock, seconds hidden to demonstrate reflow
3. Settings panel
4. Browser implementation

Avoid filling the README with many nearly identical screenshots.

## Privacy check

Before committing screenshots, check the desktop for personal names, notifications, account details, file paths, browser tabs, or other private information.
