# Third-party assets

The public source package does not include third-party font binaries.

MinimalClock uses the Windows system font `Segoe UI Light` by default. During early local development, GeosansLight was used as a visual reference. It is intentionally not distributed in this repository because redistribution rights were not established.

Users may change `FontFace` in `MinimalClock/@Resources/Settings.inc` to any font they are licensed to use.
